# Ensolvers Notes Challenge

A Full Stack application for managing notes, built with FastAPI (Backend) and React + Tailwind CSS (Frontend).

## 🚀 Features
- **CRUD Operations:** Create, read, update, and delete notes.
- **Categorization:** Filter notes using custom tags.
- **Persistence:** Relational database (SQLite).
- **Modern UI:** Responsive and intuitive design.

## 🛠️ Technologies
- **Backend:** Python, FastAPI, SQLAlchemy.
- **Frontend:** React, Vite, Tailwind CSS.

## 📦 Running the Application

This project includes automation scripts to simplify the startup process.

### Windows
Double-click the `run.bat` file. This will automatically open both the backend and frontend servers in separate windows.

### macOS / Linux
1. Open a terminal in the project's root directory.
2. Grant execution permissions to the script:
   ```bash
   chmod +x run.sh
